# K05 package report: on-device runtimes, LocalBench, capability evidence, comparison framework

Scope: everything K05 built under `src/agent_si/local`,
`src/agent_si/capability_store`, `src/agent_si/ab_framework`, the two
K05 route modules under `src/agent_si/backend`, and one additive index
migration. Fifteen product files in total (listed in section 4).

## 1. What was built, per module

### 1.1 On-device adapter, gateway and connect surface

Holding files: `src/agent_si/local/adapter.py`,
`src/agent_si/local/gateway.py`, `src/agent_si/local/__init__.py`,
`src/agent_si/backend/local_connect.py`.

- Lifecycle machine (`adapter.py`): stages SCAN through
  ROUTING_ELIGIBILITY advance exactly one step, never skipping;
  explicit model pins and split decisions (local draft plus cloud
  verification kept together) are recorded; an absent capability base
  reports NOT_CONFIGURED while routing continues; the UNKNOWN tier is
  never picked; explicit pins carry a fixed UNVERIFIED quality marker.
- Passive gateway check (`gateway.py`): an idle machine grants the
  caller a serial slot; an env-declared user bench/test run, or an
  already-held grant, refuses with a named skip reason instead of
  forcing contact.
- Connect surface (`local_connect.py`): routes
  `GET /api/v1/local/status`, `POST /api/v1/local/connect`,
  `POST /api/v1/local/disconnect`, `GET /api/v1/local/models`, each
  reaching its implementation through one named entry point; write
  calls check the UI session token first (missing or wrong token is
  refused before any state change), reads need no token.
- Package surface (`local/__init__.py`): re-exports the frozen call
  surface only.

### 1.2 Local-AI settings

Holding file: `src/agent_si/local/config.py`.

- Eight named settings error codes (scope, endpoint, model,
  permission, ambiguous field, local-only violation, decision-record
  required, config not found); one project key can never read
  another's config; only explicit endpoint/model/permission/local-only
  patch keys are accepted; every mutation carries a per-change
  decision record; local-only mode performs zero cloud calls and warns
  on weak evidence.

### 1.3 LocalBench

Holding files: `src/agent_si/local/bench_protocol.py`,
`src/agent_si/local/bench_runner.py`,
`src/agent_si/local/bench_cases.py`,
`src/agent_si/backend/localbench_routes.py`,
`src/agent_si/adapters/sqlite/migration_scripts/0390_localbench_evidence.sql`.

- Output contract (`bench_protocol.py`): Quick / Standard / Deep
  levels with staged time floors scaled by model size, result rows,
  hardware profile, CSV plus manifest output.
- Serial runner (`bench_runner.py`): one run at a time behind the
  passive check; offline-declared model ids skip with reason and touch
  no network; busy / unauthorized / forbidden-path / pull refusals
  raise and change nothing; pause and stop are supported.
- Case suite (`bench_cases.py`): frozen seeded id slices per level,
  metadata refs only.
- HTTP surface (`localbench_routes.py`): scan, estimate, runs, pause,
  resume, stop, results, history, import and check; write routes
  require the bound session token (missing gives 401, wrong gives 403,
  both with a named code and no state change); reads need no token.
- Migration `0390_localbench_evidence.sql`: index only
  (`idx_capability_evidence_fingerprint` on
  `capability_evidence_records(environment_fingerprint)`), idempotent,
  no table or column change.

### 1.4 Capability evidence store

Holding files: `src/agent_si/capability_store/store.py`,
`src/agent_si/capability_store/import_store.py`,
`src/agent_si/capability_store/__init__.py`.

- Read path serves one evidence row per model and task class, every
  row carrying a stable `cap:` reference; tiers UNKNOWN / PROXY /
  MEASURED with CURRENT / STALE / INCOMPATIBLE / UNKNOWN freshness.
- Measured rows enter only through the import path; original external
  data is never modified; stale copies stay versioned backups and are
  never served as current; both refusal codes keep the store's own
  prefix.

### 1.5 Cloud-only versus local-assisted comparison

Holding files: `src/agent_si/ab_framework/framework.py`,
`src/agent_si/ab_framework/__init__.py`.

- `run_comparison` executes both arms through the injected legs,
  repeats per arm, sums tokens / cost / time / quality, and reports
  local-assisted-minus-cloud-only deltas; arm config mismatches and
  invalid repeat counts raise named value errors.
