# K07 integration report

Scope: K07 only (shell, UX, cards, languages). Covers the three built
lanes as one integrated package: Lane A shell plus cards and surfaces,
Lane B settings plus locales plus first-run and info views, Lane C the
LocalBench settings tab. Describes only built work.

## 1. What was built

- Desktop shell: top bar, sidebar navigation, project-scoped
  runs and reports menus, closing guard, inspector.
- Card kit: card, data table, disclosure, empty and loading states,
  error panel, metric card, plain text, design tokens.
- Surfaces: chat (streaming, approval card, offline queue, abort),
  agents live view, projects with run history, task composer with
  team quick-fix, start and hierarchy run helpers.
- App views: first-run flow, migration view, how-it-works, about
  (product name, licence line, MIT text per locale), settings layout.
- LocalBench settings tab: path to scan to level to run flow,
  duration and PC-load warnings, per-model results, per-change
  decision record; client types match the served local-bench routes.
- Locales: English plus Ukrainian, 188 keys each, identical sets;
  every interface string resolves through the locale lookup, which
  raises a coded error on an unknown key.
