# Design provenance — icons

Twelve interface glyphs are inline SVG paths in `frontend/src/ui/icons.tsx`: add, folder, settings, expand-more, chevron-right, send, attach-file, microphone, description, play, visibility, and bar-chart. They render with the current text color on a 24-pixel grid.

Source: Material Icons by Google, under the Apache License, Version 2.0. The bar-chart glyph is transcribed from bars to path form; the shapes are otherwise unchanged.
